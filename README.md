# 言逸点点-离线版

原"布灵点点-高级版"按键脚本工具的离线复刻版。无需登录授权码、无任何联网验证，全部功能本地运行。

- GitHub：[714248411/DianDianQi](https://github.com/714248411/DianDianQi)
- Gitee：[一只言逸/点点器](https://gitee.com/YiZhiYanYi/DianDianQi)

## 快速开始

直接双击 `言逸点点器.exe`，启动即进入主界面，无任何弹窗和登录。
热键：**F9** 执行当前任务，**F10** 停止脚本（可在"设置"里改）。

标题栏提供“**捐赠**”“**关于**”“**更新说明**”入口：捐赠二维码随程序离线提供；关于页展示当前版本与官方联系信息；更新说明记录本次功能与文档变化。

## 三大视图

| 视图 | 用途 |
|------|------|
| 初级视图 | 快速建任务：任务名称、重复次数、窗口绑定、后台模式配置、图色模板截取、操作录制、AI识图测试、DLL管理；任务流程小预览实时联动编辑/多功能，点击预览直达编辑视图，"打开多功能代码"一键跳转 |
| 编辑视图 | 流程图编程：右键画布添加节点（开始/结束/自定义/延迟/鼠标/键盘/找图/找色/AI识图/找字/判断/循环），节点间拖箭头连线，双击节点配置，支持模板保存/插入、任务导入/导出、缩放平移 |
| 多功能 | 代码编程：左侧命令面板（点击显示用法、双击/生成代码插入），右侧多标签代码编辑器（语法高亮） |

## 视图联动（同步机制）

- 初级视图 ⇄ 多功能：初级视图左下"打开多功能代码"直接打开当前任务的代码页；多功能里改代码实时写回任务，初级视图的流程预览与"节点/代码"统计同步刷新
- 初级视图执行时，若流程图只有默认"开始/结束"而任务代码有内容，则直接执行多功能代码
- 初级视图改任务名称 → 任务页签、多功能代码页签同步重命名
- 录制器"转为多功能代码" → 直接生成多功能新代码页并切换过去
- 编辑视图任务切换 → 多功能自动切换到对应任务代码页；自定义节点可"在多功能中编辑"，改动自动写回节点

## 键盘鼠标录制器（初级视图 → 录制页）

录制鼠标移动、左/中/右键按下抬起、单击、双击、拖动、滚轮，以及键盘按键（含 CTRL/SHIFT/ALT/WIN 组合、按住自动连击、长按按下抬起）。
可选项：记录鼠标移动、记录时间延迟（自动插入"延迟(ms)"）、合并双击。
录制完毕点"**转为多功能代码**"直接生成多功能代码页；也可生成"自定义"节点或复制代码。

## DLL 全部可用（初级视图 → DLL 页 + 脚本命令）

- 初级视图新增"**DLL**"页：自动检测程序目录下所有 DLL 的架构（x64/x86）、导出函数数量、类型（可调用插件/.NET程序集/运行库依赖）与状态，支持查看导出函数、测试加载、一键生成调用代码
- 脚本命令：`加载DLL("xx.dll")`、`调用DLL(句柄, "函数名", 参数...)`（stdcall）、`调用DLL函数(...)`（cdecl）、`卸载DLL(句柄)`、`获取DLL导出("xx.dll", 数组)`
- 64 位 DLL 本进程直接调用；**x86 DLL 自动经 `DllBridge32.exe` 桥接调用**（独立小进程，参数个数精确匹配，stdcall/cdecl 均支持），整个目录的 DLL 都能被脚本使用
- Qt5/opencv/paddle/onnxruntime 等 DLL 是内置工具（buke_*）的运行库依赖，随程序自动加载

## 脚本语言（与原版一致）

```
# 注释
变量 a = 5
b = "字符串"
c = 1.5

如果(a == 5)
开始
    鼠标左键单击(100, 200)
结束
否则如果(a == 6)
开始
    键盘单击(A, 5, 100)
结束
否则
开始
    鼠标移动(300, 400, 10, 10, 10, 10, 3, 200)
结束

循环(1)
开始
    跳出循环
结束

子任务 我的函数(x, y)
    返回 x + y
子任务完成

a = 我的函数(1, 2)
消息框("标题", "结果: ", a)
```

已实现全部 108 条内置命令：鼠标（16条，含随机偏移/次数/间隔）、键盘（8条）、图色查找（找色/多点找色/找图/找多图/截图）、文本识别查找（离线OCR，走 Umi-OCR 引擎）、窗口、进程、文件、字符串剪贴板、时间日期、数学、类型转换、多线程、多任务/多线程锁、加速延迟、鼠标轨迹等，用法与原版 doc 文档一一对应。

## 目录说明

- `言逸点点器.exe` — 主程序（零依赖，.NET Framework 4 WinForms）
- `DllBridge32.exe` / `DllBridge64.exe` — DLL 桥接器（让 x86/x64 DLL 都能被脚本调用）
- `src\` — 全部 C# 源码（`Recorder.cs` 录制器、`DllHost.cs` DLL 宿主）
- `bridge\DllBridge.cs` — 桥接器源码
- `build.ps1` — 编译脚本（用系统自带 csc.exe，无需安装任何东西）
- `assets\donation_qr.png` — 随程序附带的捐赠二维码图片
- `CHANGELOG.md` — 版本更新说明
- `test.ps1` — 无头自测（72 项：解释器/图色/流程图执行器/任务序列化/DLL调用）
- `ocrtest.ps1` — OCR 冒烟测试
- `模板图片\` — 找图模板目录（初级视图"图色"页截取后保存在此）
- `模板\` — 流程节点模板
- OCR 引擎：自动调用 Umi-OCR（同机安装原版时），以本地 HTTP 服务方式离线运行，首次识别需等待模型加载

## 与原版的差异

- 无登录/授权码（直接进入）
- 任务文件为自研 JSON 格式（.btask），不兼容原版二进制 .svs
- 后台模式以兼容方式运行（句柄消息），前台模式全功能
- 目标检测（YOLO）接口保留、返回空（原版需额外训练模型）

## 构建

在 Windows 10/11 上双击 `build.bat`，或运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
```

构建成功后会在项目根目录生成 `言逸点点器.exe`、`DllBridge32.exe` 和 `DllBridge64.exe`。运行主程序时请保留 `assets` 目录，以便显示捐赠图片。
